# **App Name**: CampusFlow

## Core Features:

- Campus Location Discovery & Search: Allows users to efficiently search and browse campus locations, applying filters such as classroom, office, or department to refine results.
- Google Maps Navigation Integration: Enables users to launch external Google Maps for precise walking directions to any selected campus location, leveraging latitude and longitude data.
- Real-time Campus Updates & Notices: Displays an organized list of current campus announcements and notices, with filtering options for categories like Exams, Admissions, and General information.
- AI Assistant Chatbot: An interactive chatbot powered by the Gemini API, designed as a campus assistant tool to answer student queries, with a fallback mechanism to predefined FAQ responses.
- Admin Panel for Content Management: Provides a secure administrative interface for creating, editing, and deleting campus locations and notices, ensuring content is always up-to-date.
- Personalized Quick Access Dashboard: A centralized home screen featuring a search bar, customizable quick-action cards (e.g., Fee Vouchers, Results), and a dynamic display of recent campus updates.
- Admin Authentication: Secures access to the administrative panel through a dedicated login system, protecting content management functionalities.

## Style Guidelines:

- The primary color is a deep, sophisticated blue (#174DE3), selected to convey trustworthiness and institutional reliability. This hue serves as the foundation for branding and key interactive elements.
- The background color is a very light, almost white-blue (#F7F9FC). This choice provides a clean, open canvas, maintaining a subtle connection to the primary blue while ensuring excellent readability and visual comfort.
- An accent color of vibrant sky blue (#5CC9ED) is used to draw attention to critical calls-to-action, navigation elements, and important highlights, creating dynamic contrast with the primary and background hues.
- The font 'Inter', a versatile grotesque-style sans-serif, is recommended for both headlines and body text. Its modern, clear, and objective aesthetic supports readability across all content types and aligns with the app's professional guidance.
- The layout emphasizes a mobile-first, responsive design with clear, card-based components. Consistent rounded corners (12px+) and standardized spacing are used throughout to create a clean, modern, and user-friendly interface.
- Clean, modern, and universally understandable icons will be used. These will likely be filled or solid line-art icons that complement the contemporary UI and clearly communicate functionality.
- Subtle UI animations such as loading skeletons for content fetching, and distinct toast/snackbar notifications for user feedback and error handling, will enhance the perceived performance and user experience.
